FAQ

“Deposit problem” card kholein → User name aur mobile number likhein → Email id bharein → Deposit amount enter karein → Payment image upload karein → Submit Now dabayein → Review screen me Confirm karein.

“Withdrawal problem” card kholein → User name, mobile number aur email id bharein → Withdrawal amount likhein → Issue ki screenshot upload karein → “Submit Now” dabayein → Review me Confirm karein.

“E-mail verification” card kholein → User name, UID aur mobile number bharein → Verification ke liye email id likhein → Issue ki screenshot upload karein → “Submit Now” dabayein.

“Online chat” card kholein → Neeche message box me text likhein → Send button dabayein. Message chat history me save ho jata hai; Clear history se hata sakte hain.

Submit dabane par review screen aati hai → Details check karke Confirm karein → Complaint ID milti hai → Inbox me jaakar complaint ki details aur status dekh sakte hain.
